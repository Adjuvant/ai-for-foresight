# Knowledge Base

The Obsidian vault directory is `fnl-aii/`. Read `.toolkit.json` for this value. In toolkit instructions, `<vault>/` means this directory.

## Filing issues

Follow [`CONTRIBUTING.md`](CONTRIBUTING.md). Start the issue body with `Found in:` and `Blocking:` lines, and add the `dogfood` label when filing in a repo you are not working in.

## Repo boundaries

**Repo boundaries.** Work within the repos authorized by the owner’s task. For a change in another repo under op-projects, or to the workspace baseline, file a request in the owning repo using the issue-filing convention and have it evaluated before editing. An existing owner mandate covering multiple repos authorizes that scope; continue without asking again.

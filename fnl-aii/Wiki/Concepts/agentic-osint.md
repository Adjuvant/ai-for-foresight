# Agentic OSINT

LLM agent pipelines repurposed for open-source intelligence (OSINT) gathering; the pattern is commodity agentic stacks (model + MCP/REPL tool layers) specialised with OSINT skill packs, plus commercial incumbents folding agentic features into existing collection infrastructure.

## Key Claims
- Open-source agentic OSINT tooling such as OpenOSINT repurposes commodity LLM agents (Claude/GPT-4/local models) with a REPL, MCP server and CLI tool layer rather than bespoke AI architectures, and is scoped to authorised security research only [1] [[Literature/agentic-signal-intelligence#^agentic-signal-intelligence-1]].
- Commercial real-time intelligence platforms (Dataminr, Recorded Future, Perigon, GreyNoise) absorb LLM/agentic features into existing collection and sensor infrastructure rather than being replaced by new entrant agents [4][5][7][8] [[Literature/agentic-signal-intelligence#^agentic-signal-intelligence-4]] [[Literature/agentic-signal-intelligence#^agentic-signal-intelligence-5]] [[Literature/agentic-signal-intelligence#^agentic-signal-intelligence-7]] [[Literature/agentic-signal-intelligence#^agentic-signal-intelligence-8]].
- Dataminr's claimed user base — 100+ US government agencies, with NATO and OpenAI reported as customers — is vendor-reported and not independently verified as of the Aug 2026 scan [5][6] [[Literature/agentic-signal-intelligence#^agentic-signal-intelligence-5]] [[Literature/agentic-signal-intelligence#^agentic-signal-intelligence-6]].

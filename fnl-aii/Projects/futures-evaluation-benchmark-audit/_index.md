# Futures Evaluation Benchmark Audit

## Scope

An audit of how futures work gets evaluated — from institutional horizon scanning and commissioned speculative narrative (science-fiction planning) to LLM-assisted foresight — and a design proposal for a lightweight, evidence-grounded benchmark audit that scores an intervention's evaluation readiness against the field's verified failure modes (training-data contamination, backtest leakage, single-threshold metric distortions). Draws on the `foresight-evaluation` and `science-fiction-planning` concept threads in this vault.

## Research Questions

- RQ1: Which evaluation designs (prospective tournaments, dynamic future-only benchmarks, chronological backtests with leakage audits, calibration scoring, process metrics) are applicable to speculative-narrative foresight interventions, and which are not?
- RQ2: What verified evidence exists that any futures-work program — commissioned SF, experiential futures, institutional scanning — has been evaluated for impact on decisions?
- RQ3: Can evaluation readiness be scored cheaply from existing verified claims (benchmark contamination rates, backtest leakage bounds, event resolution practices) without new field experiments?
